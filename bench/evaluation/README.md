# Syntax evaluation seed

Twelve original synthetic regression cases cover success returns and near misses across Python, JavaScript and TypeScript. They have no independent reviewer labels and are not an independent holdout. The repository license applies to these original examples. No third-party source was imported.

Run `prufgate evaluate --cases bench/evaluation --format html --output reports/accuracy.html` from the repository root. See `docs/EVALUATION.md` for labels, scoring, source permissions and the remaining independent-evidence acceptance work. Keep cases as `.txt` so intentionally flawed example code is not executed or mistaken for the product source.
